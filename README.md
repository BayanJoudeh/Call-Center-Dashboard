# Call Center Performance Dashboard

This repository contains a Power BI dashboard that visualizes key metrics for a call center's performance.

## 📊 Dashboard Overview

The dashboard includes the following metrics and visuals:

- **Resolved Call Count**: 3646  
- **Unresolved Call Count**: 1354  
- **Total Answered Calls**: 4056  
- **Total Unanswered Calls**: 944  
- **Agent Performance**: Total calls handled by each agent (e.g., Jim, Martha, Dan, etc.)  
- **Monthly Call Volume**: Distribution of calls across months  
- **Call Response Statistics**: Proportion of answered vs. unanswered calls  
- **Average Call Response Time**: Displayed using a gauge chart  
- **Satisfaction vs. Response Speed**: Bar chart comparing satisfaction rating and answer speed
